# Code of conduct

Hubzz UI should be a professional and useful public project. Contributors and maintainers are expected to communicate in a way that makes technical collaboration easier.

## Expected behavior

- Be respectful and specific when discussing code, design, accessibility, and tradeoffs.
- Critique the work rather than the person.
- Assume good intent while still asking for evidence, tests, or clearer reasoning when needed.
- Make room for different experience levels and explain project conventions when they are relevant.
- Keep review comments focused on the repository and the change under discussion.
- Respect privacy and never post another person's private information, credentials, or communications without permission.

## Unacceptable behavior

Harassment, threats, discriminatory language, deliberate intimidation, personal attacks, sexualized conduct, doxxing, and sustained disruption are not acceptable in repository spaces.

## Enforcement

Maintainers may edit, hide, lock, or remove content that violates these expectations and may restrict participation when necessary to protect the project and its contributors.

If you need to report conduct privately, contact the repository maintainer through GitHub rather than escalating the issue in a public thread.
